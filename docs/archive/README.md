# Historical instruction snapshots

These files preserve the exact pre-2026-09-09 instruction content for audit and
recovery. They are not active agent instructions and are not required startup
reading. The root `AGENTS.md`, its linked current standards, and the project's
existing design/decision sources define current work.

The consolidation keeps repository-specific architecture, safety, verification
and ownership rules while removing contradictory startup commands and mandatory
paperwork for small tasks. No product scope, source layout, engine version or
model selection is changed by this consolidation. Consult a historical snapshot
only for a concrete past incident; do not restore an obsolete command as policy.
